# BitModel: Decentralized AI Model Distribution via BitTorrent

*Renamed from [LlamaTor](https://github.com/Nondzu/LlamaTor).*

BitModel is a community-driven project that offers a decentralized, efficient, and user-friendly method for downloading and distributing AI models. By leveraging the robustness of the BitTorrent protocol, BitModel enables the creation and sharing of torrent files for AI models, ensuring model distribution is not solely dependent on any centralized site.

**Pre-generated torrent files are available in the [LlamaTor Torrents Branch](https://github.com/Nondzu/LlamaTor/tree/torrents/torrents). Download and use them with a torrent client like [qBittorrent](https://www.qbittorrent.org/).**

## Requirements

All scripts are self-contained [uv](https://docs.astral.sh/uv/) scripts with inline dependency metadata. No virtual environment or `pip install` needed — just run them with `uv run`:

```bash
uv run generate.py --help
```

Or make them executable and run directly:

```bash
chmod +x generate.py
./generate.py --help
```

## How to Use BitModel

### 1. Generate a JSON file with the structure of AI models

`generate.py` queries the Hugging Face Hub API to build a JSON list of models and their files.

```bash
uv run generate.py --user mlx-community --filter gemma-4 --limit 5 --age 365 --verbose
```

**Options:**

| Option | Description |
|--------|-------------|
| `--user` | Filter by author/org (e.g. `mlx-community`, `TheBloke`) |
| `--filter` | Search terms to match in model names (repeatable) |
| `--trending` | Discovery mode: fetch trending models (no `--user`/`--filter` needed) |
| `--sort` | Sort by `last-modified`, `downloads`, `likes`, `trending`, or `name` |
| `--limit` | Max number of models to process |
| `--age` | Max age in days; older models are skipped (default: 30) |
| `--pipeline-tag` | Filter by task (e.g. `text-generation`, `image-classification`) |
| `--params` | Filter by parameter count (e.g. `min:1B,max:7B`, `max:3B`) |
| `--skip-gated` | Exclude gated models that require access requests |
| `--remove-duplicates` | Remove models that already have torrents |
| `--filename` | Output filename prefix |
| `--verbose` | Show trending/downloads/likes for each matched model |

**Examples:**

```bash
# Top 10 trending text-generation models
uv run generate.py --trending --pipeline-tag text-generation --limit 10 --verbose

# Most downloaded models from a specific org, under 7B params
uv run generate.py --user mlx-community --sort downloads --params "max:7B" --limit 20

# Search by name
uv run generate.py --filter "Llama-3" "gemma" --limit 10 --age 90
```

### 2. Download AI models

`download.py` downloads all models listed in a JSON file generated by `generate.py`.

```bash
uv run download.py -o /media/user/models/ --models-file ./my_models-models.json
```

**Options:**

| Option | Description |
|--------|-------------|
| `-o`, `--output-directory` | The folder where models will be saved (required) |
| `--models-file` | The JSON file containing models to download (required) |
| `--timeout` | Download timeout in seconds (default: 30) |
| `--verbose` | Enable verbose output |

### 3. Generate torrent files for AI models

`make_torrent.py` generates hybrid v1+v2 torrent files for downloaded models. Hybrid torrents work with all clients — older clients use the v1 metadata, newer clients benefit from v2's SHA-256 hashes and per-file deduplication.

```bash
uv run make_torrent.py -i /path/to/models -o /path/to/torrents
```

**Options:**

| Option | Description |
|--------|-------------|
| `-i`, `--input-directory` | Folder containing downloaded models (required) |
| `-o`, `--output-directory` | Folder for generated torrent files (required) |
| `--filter` | Glob pattern for folder names, e.g. `*AWQ*` (default: `*`) |
| `--piece-size` | Piece size in bytes (default: 2097152 / 2 MiB) |
| `--print-magnets` | Print magnet links to stdout |
| `--magnets-file` | Append magnet links to this file |
| `--magnet-tracker-count` | Trackers to include in magnet links: a number or `all` (default: 5) |

**Examples:**

```bash
# Generate torrents and save magnet links
uv run make_torrent.py -i models -o torrents --print-magnets --magnets-file magnets.txt

# Only process specific folders
uv run make_torrent.py -i models -o torrents --filter "*gemma*"
```

## Contributing

Code contributions (bug fixes, new features, improvements) are welcome here — open a PR or issue on this repo.

For `.torrent` file contributions, please file those against the upstream [LlamaTor](https://github.com/Nondzu/LlamaTor) repo, which maintains a [torrents branch](https://github.com/Nondzu/LlamaTor/tree/torrents/torrents).

### Support the ecosystem

1. **Seed Torrents:** After downloading a model, keep your torrent client open so others can download from you. The more seeders, the faster the download speed for everyone.
2. **Spread the Word:** Share the project with your friends, colleagues, and social media networks to help grow the community.
3. **Donate:** This is a fork of [LlamaTor](https://github.com/Nondzu/LlamaTor) — consider supporting the upstream project as well. If you'd like to support this fork's development directly, donations are appreciated too.
